8//! Key management for leader election.
9//!
10//! A single key holds the durable coordination state. It stores the relative
11//! lease duration, but no clock reading, absolute timestamp, renewal time, or
12//! expiry deadline. Takeover timing is a local caller concern.
13//!
14//! # Value schema
15//!
16//! ```text
17//! (schema_version: u64, revision: u64, has_owner: bool, owner: String,
18//!  has_lease_duration: bool, lease_duration_secs: u64,
19//!  lease_duration_subsec_nanos: u32)
20//! ```
21//!
22//! The schema version is decoded strictly. Untagged layouts from development
23//! versions of this recipe are unsupported: clear the election subspace before
24//! using this version of the recipe. The election revision is also the fencing
25//! rank for every paired ranked register, so clear those register subspaces
26//! before reuse as well. Leaving an older register fence in place rejects the
27//! new election's lower ranks.
28
29use crate::tuple::Subspace;
30
31const STATE_PREFIX: &str = "state";
32
33/// Returns the single durable election-state key.
34pub(crate) fn state_key(subspace: &Subspace) -> Vec<u8> {
35    subspace.pack(&(STATE_PREFIX,))
36}
