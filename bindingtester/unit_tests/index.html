The UNIT_TESTS instruction: a port of the Python bindings unit tests (bindings/python/tests/unit_tests.py, cancellation_timeout_tests.py and size_limit_tests.py).

A failed check panics, which makes the harness report the tester as failed, like the exception the Python tester raises. Unexpected FDB errors go back to the retry loop of each test, as in Python.

Waiting never uses the wall clock: delay waits on a transaction timeout, so the time comes from the FDB client.
