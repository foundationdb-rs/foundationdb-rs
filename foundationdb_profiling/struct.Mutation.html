Expand description

A mutation (MutationRef), normalized like the C++ deserializer does.

The optional mutation checksum and accumulative checksum index (7.4+, only when the client enables them) are stripped from param2 and their flag bits cleared from mutation_type. A single-key clear, which the wire encodes compactly, is expanded back to ClearRange(key, key + \x00).

Fields§

§mutation_type: u8

MutationRef::Type code (0 SetValue, 1 ClearRange, 2 AddValue, …).

§param1: Vec<u8>

Key, or range begin for ClearRange.

§param2: Vec<u8>

Value/operand, or range end for ClearRange.
